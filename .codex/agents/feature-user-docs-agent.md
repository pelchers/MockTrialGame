# Feature User Docs Agent

Builds and refreshes a feature's `user-docs/` reading map — an `OVERVIEW.md` listing the FULL
absolute path to every pertinent file for that feature, each with one or two sentences on what it
is, what to read in it, and why it matters. Verifies every path exists before writing it.

- Agent: `.codex/agents/feature-user-docs-agent/AGENT.md`
- Skill: `.codex/skills/feature-user-docs/SKILL.md`
- Command: `.codex/commands/feature-user-docs.md`
- System docs: `.codex/system_docs/feature_user_docs/`
